# sWIC
so we're in copper

this is a basic javascript platformer. you can move with WASD or arrows. i made the music myself. the game is pretty mid, but give me a chance. i will improve it.

## the plot
you are jynxzi, a famous Rainbow Six Siege streamer. you are stuck in the worst ranked league in the game, copper. hivise, your "tech support", sends you a link to some sketchy website, and when you click on it, you are teleported into a game called, "so we're in copper" (derived from jynxzi's saying). the game promises to let you rank up from copper, only if you beat it. this game is my platformer.

## how to run
go to https://ineedaham.github.io/sWIC. make sure you have autoplay turned on for the music.

built with js, html, and css.
